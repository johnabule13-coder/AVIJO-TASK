## 🔒 Privacy & Security Guarantees

### What Happens to Your PDFs
- ✅ Files stay on your device (never uploaded)
- ✅ No cloud storage, no servers, no APIs
- ✅ No tracking or analytics
- ✅ No file copies or backups
- ✅ All processing happens locally

### Open-Source Foundation
- **PDF.js** (pdfjs-dist v3.11.174)
  - By Mozilla Foundation
  - License: Apache 2.0 (commercial use ✅)
  - Runs entirely in-browser
  - No external API calls

### Permissions (What We Need & Why)
| Platform | Permission | Why | What We Do | What We Don't |
|----------|-----------|-----|-----------|--------------|
| Android | `READ_EXTERNAL_STORAGE` | To open PDFs you select | Read files you choose | Scan storage, upload, copy |
| iOS | File Picker | To access your Files app | Use native file picker | Access without user action |
| Web | LocalStorage | Remember recent files | Store metadata only | Store content |

## 📱 App Store Requirements

### For Google Play Store

**Add to `AndroidManifest.xml`:**
```xml
<!-- File reading for PDFs -->
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<!-- Android 11+: Scoped storage for documents -->
<uses-permission android:name="android.permission.READ_MEDIA_DOCUMENTS" />
```

**Update privacy policy in store:**
> "PDF Reader: Opens PDF files from your device storage. Files are processed locally and never uploaded. No cloud storage, no tracking. All functionality works offline."

## 🆘 Common Questions

### Q: Can users see recent files forever?
**A:** No. Recent files list clears when users:
- Delete app cache
- Clear browser storage
- Uninstall and reinstall the app
- Reset browser data

### Q: What if a PDF is corrupted?
**A:** Shows a friendly error message: "Error loading PDF: [reason]"
App never crashes, user can try another file.

### Q: Does it work on slow internet?
**A:** Yes! First load needs PDF.js (from CDN), then works fully offline.
Recommend: Preload PDF.js on first app launch or WiFi.

### Q: What about GDPR/CCPA compliance?
**A:** Fully compliant because:
- No personal data collection
- Files stay on user's device
- No tracking or profiling
- User has full control
- Offline capable (no cloud dependency)

### Q: Can we add ads or analytics?
**A:** Recommended against for privacy + app store. Current design is perfect for:
- 🏆 Google Play "privacy-focused" badge
- 🏆 Apple App Store privacy label compliance
- 🏆 GDPR/CCPA compliance
