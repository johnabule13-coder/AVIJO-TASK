Accessibility Statement

Last Updated: November 2024

WCAG 2.1 AA Compliant

Our Commitment to Accessibility

AVIJO TASK PRO is committed to ensuring digital accessibility for people with disabilities. We continually strive to increase the usability and accessibility of our application to serve all our users, including those with disabilities.

Accessibility Features

Keyboard Navigation

  • All interactive elements are keyboard accessible
  • Tab order follows logical flow
  • Keyboard shortcuts for common actions

Screen Reader Support

  • ARIA labels and descriptions for all controls
  • Proper semantic HTML structure
  • Live regions for status updates
  • Compatible with JAWS, NVDA, and VoiceOver

Visual Accessibility

  • High contrast color schemes (WCAG AAA compliant)
  • Customizable text sizes
  • Support for light and dark modes
  • No reliance on color alone to convey information
  • Readable font sizes and weights

Motor Accessibility

  • Large touch targets (minimum 44x44 pixels)
  • No time-limited interactions
  • Customizable animation (respects prefers-reduced-motion)
  • No complex gestures required

Cognitive Accessibility

  • Clear, simple language
  • Consistent navigation patterns
  • Helpful error messages and guidance
  • Logical content organization

WCAG 2.1 Compliance

AVIJO TASK PRO aims to conform to WCAG 2.1 Level AA standards. This includes:

  • Perceivable: Information is presented in multiple modalities
  • Operable: All functionality is keyboard accessible
  • Understandable: Content is clear and navigation is predictable
  • Robust: Compatible with assistive technologies

Known Limitations

While we strive for full accessibility, certain limitations may exist:

  • Third-party APIs (Free Dictionary API) may have their own accessibility limitations
  • Media player controls follow platform-specific implementations
  • Some advanced features may require specific platform support

Assistive Technology Support

AVIJO TASK PRO supports:

  • Screen readers (JAWS, NVDA, VoiceOver)
  • Speech recognition software
  • Magnification tools
  • High contrast modes
  • Text-to-speech functionality
