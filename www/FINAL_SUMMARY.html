⚡ Troubleshooting

IP Address Not Working?

Try these alternative addresses:

  • http://192.168.8.7:8000 (Primary - try this first)
  • http://169.254.217.216:8000 (Backup)
  • http://localhost:8000 (Only works on the computer)

App Won't Load?

Make sure:

  • Your phone is connected to the same Wi-Fi network as your computer
  • You're using the correct IP address (192.168.8.7)
  • The web server is running on your computer
  • Try refreshing the page (F5)
