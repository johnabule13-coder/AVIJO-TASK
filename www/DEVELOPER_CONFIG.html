🎮 Video Player Configuration

Configure the video player in pro-player.js:

Player Initialization

// Auto-initialized on page load // Access via: window.avijoPlayer const player = window.avijoPlayer; // Configuration player.playlist = ['video1.mp4', 'video2.mp4']; player.currentIndex = 0; player.playbackRate = 1; player.autoplay = false;

Player Methods

Method Parameters Returns
playNext() None void
playPrevious() None void
setPlaybackRate(rate) number (0.5-2) void
setQuality(quality) string ('480p'-'4K') void
seek(time) number (seconds) void
setVolume(volume) number (0-1) void

Player Usage Example

// Get player instance const player = window.avijoPlayer; // Add videos player.addToPlaylist('intro.mp4'); player.addToPlaylist('content.mp4'); player.addToPlaylist('outro.mp4'); // Control playback player.playNext(); player.seek(30); // Seek to 30 seconds player.setPlaybackRate(1.5); // 1.5x speed player.setVolume(0.7); // 70% volume // Get information console.log(player.getDuration()); // Video length console.log(player.getCurrentTime()); // Current position console.log(player.getPlaylist()); // All videos

⚙️ Settings Manager Configuration

Configure user settings with window.avijoSettings:

Settings Structure

{ theme: 'dark', // 'dark', 'light', 'auto' quality: 'auto', // '480p', '720p', '1080p', '4K' playbackRate: 1, // 0.5 to 2 volume: 0.8, // 0 to 1 autoplay: false, // true/false captions: false, // true/false pip: true, // Picture-in-Picture keyboard: true, // Keyboard shortcuts notifications: true // User notifications }

Settings Methods

Method Purpose Example
getSetting(key) Get individual setting getSetting('theme')
setSetting(key, value) Set and persist setting setSetting('quality', '1080p')
loadSettings() Load from localStorage loadSettings()
saveSettings() Save to localStorage saveSettings()
exportSettings() Export as JSON string const backup = exportSettings()
importSettings(json) Import from JSON string importSettings(backup)

Settings Usage Example

const settings = window.avijoSettings; // Get setting const theme = settings.getSetting('theme'); const quality = settings.getSetting('quality'); // Set setting settings.setSetting('theme', 'light'); settings.setSetting('quality', '1080p'); settings.setSetting('playbackRate', 1.5); settings.setSetting('volume', 0.9); // Export user settings const backup = settings.exportSettings(); localStorage.setItem('my_backup', backup); // Import user settings const imported = localStorage.getItem('my_backup'); settings.importSettings(imported);

🔒 Security Configuration

Content Security Policy (CSP)

Add this meta tag to your index.html for security:

<meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self' 'unsafe-inline'; style-src 'self' 'unsafe-inline' https://fonts.googleapis.com; font-src 'self' https://fonts.gstatic.com; img-src 'self' data:; connect-src 'self' https://api.dictionaryapi.dev">

X-Frame-Options

<meta http-equiv="X-UA-Compatible" content="IE=edge"> <meta http-equiv="X-Frame-Options" content="SAMEORIGIN">
