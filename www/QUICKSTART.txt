## Common Questions (Answered)

**Q: Do users need internet?**
A: Only for the first load (PDF.js from CDN).
   After that, 100% offline.

**Q: Are files uploaded anywhere?**
A: No. 100% local processing. Files stay on device.

**Q: What if a PDF is corrupted?**
A: Shows friendly error. App never crashes.

**Q: Does it work on mobile?**
A: Yes! Touch-optimized, responsive design.

**Q: Can I customize the colors?**
A: Yes! pdf-reader.js uses your CSS theme variables.

**Q: How do users open PDFs?**
A: Native file picker (Android) or Files app (iOS).

**Q: What if I delete the app?**
A: Clears recent files & bookmarks (normal).
  PDFs remain on device in original location.

**Q: Does it support password-protected PDFs?**
A: Yes! Prompts for password on load.

**Q: Can users zoom?**
A: Yes! Zoom In/Out/Fit Width/Reset buttons + pinch.

**Q: Does text search work?**
A: Yes! Full-text search with result highlighting.
