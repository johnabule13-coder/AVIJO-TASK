AVIJO TASK PRO ("we," "us," "our," or "Company") is committed to protecting your privacy. This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our mobile application and web platform (collectively, the "Service").

2. Information We Collect

We collect information in the following ways:

  1. Local Data: Notes, plans, words, and media you create are stored locally on your device using browser storage. We do not automatically upload this data to our servers.
  2. Optional Cloud Sync: If you choose to sign in with Claude, your data can be synced to your personal account for access across devices.
  3. Media Files: You choose which files to access. We do not download, upload, or transmit your media files anywhere.

  5. Device Information: We collect non-personal device information for compatibility and performance improvement.

13. PDF Reader Feature

The AVIJO TASK PRO PDF Reader is a fully offline document viewer with the following privacy characteristics:

File Access & Storage

  • Local Processing Only: All PDF files are processed locally on your device. No files are uploaded to any server or cloud service.
  • File Picker Permission: The app requests permission to access your device's file system only when you explicitly choose to open a PDF. This permission is device-level and can be revoked at any time in your browser or app settings.
  • Recent Files Tracking: File metadata (name, size, access date) is stored locally in browser storage for convenience. No file content is stored remotely.
  • Last Page Memory: Your reading position in each PDF is saved locally on your device so you can continue where you left off.

What AVIJO TASK PRO Does NOT Do

  • ❌ Does not upload PDF files anywhere
  • ❌ Does not send file content to external services
  • ❌ Does not use OCR services or external APIs for PDF processing
  • ❌ Does not share file metadata with third parties
  • ❌ Does not create copies of your files on cloud storage
  • ❌ Does not track which PDFs you open (locally saved data only)
  • ❌ Does not embed tracking pixels or analytics in PDF viewing
  • ❌ Does not mine or analyze PDF content

Libraries and Dependencies

PDF.js (pdfjs-dist):

  • Open-source library by Mozilla Foundation
  • License: Apache 2.0 (Commercial-friendly)
  • Runs entirely in-browser for rendering
  • Worker script loaded from CDN but executes on your device
  • No data leaves your device during PDF processing

Supported File Features

  • Text-based PDFs (full search and copy support)
  • Scanned PDFs (images, no text extraction)
  • Password-protected PDFs (password verification happens locally)
  • Large files (lazy page rendering prevents slowdowns)
  • PDFs with images, forms, and embedded content
  • Corrupted files (graceful error handling)

Permissions Explanation for App Stores

Android File Access Permission:

  • What it means: Permission to read files you select from your device storage
  • Why we need it: To open PDF files from your Downloads, Documents, or any folder you choose
  • How we use it: Only when you tap "Open PDF" and select a file; we do not scan or index your file system
  • What happens to files: Never copied, uploaded, or retained after viewing
  • Revocation: You can revoke access anytime in Settings > Apps > AVIJO TASK PRO > Permissions

    • iOS Document Access:

    • Uses the native file picker when available
    • Does not store files in app's Documents folder without your consent
    • Respects Files app sandboxing
    • Compatible with "Open with AVIJO" / share-to-app workflows

    Dark Mode & Accessibility

    • PDF viewer respects your device's dark mode preference and system theme
    • All controls are keyboard-accessible
    • Touch-friendly zoom and navigation for mobile
    • High-contrast text for readability

    Offline Functionality

    The PDF reader works completely offline after the initial app load. No internet connection is required to:

    • Open local PDF files
    • Navigate pages
    • Zoom and search
    • Read password-protected PDFs
    • Access recent files list

    Data Deletion

    • Recent files list is cleared when you clear app cache/cookies
    • Last-page bookmarks are stored only on your device
    • Clearing browser data removes all PDF reader settings
    • No residual data remains after deleting the app (except system-level file access logs)

    Summary: Your PDFs are yours and yours alone. AVIJO TASK PRO's PDF reader is designed with privacy-first architecture—all processing happens on your device, no files are shared with anyone, and you maintain complete control over your documents at all times.
